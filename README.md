# Dailies 🗓️

Dailies is a clean, fast, and engaging social media platform built for sharing daily thoughts, media, and interactions. It includes user profiles, a home feed, likes, comments, notifications, and a sleek design inspired by minimalism.

## 🔗 Live Demo
[Visit Dailies](https://dailies-social.vercel.app)

## 🚀 Features
- 🏠 Personalized Home Feed
- 🧑 User Profiles & Following System
- ❤️ Like & 💬 Comment on Posts
- 🔔 Real-Time Notifications
- 📱 Mobile Responsive UI

## 🛠️ Stack
- **Frontend**: Next.js, Tailwind CSS, Framer Motion
- **Backend**: Next.js API Routes, Prisma
- **Database**: PostgreSQL
- **Storage**: UploadThing for images
- **Auth**: Clerk (or your auth choice)

## 📊 Project Impact
- 🚀 Launched MVP with 120+ signups in first week
- ⚡ Reduced post load time by 40% with image optimization
